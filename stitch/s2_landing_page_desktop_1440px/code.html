מה קורה אם אין לי את החשבונית? ▾

אפשר להעלות תעודת אחריות, אישור התקנה, או להזין את פרטי הרכישה באופן ידני. המערכת תסמן את המועד כמשוער לפי קטגוריית המוצר.

מי יכול לראות את המסמכים שלי? ▾

רק משתמשים שהזמנתם באופן מפורש למרחב שלכם. אתם שולטים על הרשאות הגישה בכל עת וניתן להגדיר חברים לצפייה בלבד.
